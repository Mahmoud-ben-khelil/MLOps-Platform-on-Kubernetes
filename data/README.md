# data/

Only `titanic.csv` is committed. Every other file in this folder is either
downloaded by a script or generated by the training code, and is ignored by
git (see the root `.gitignore`).

Run the commands below from the repository root.

## Demo datasets

### `scripts/download_demo_datasets.py`

```powershell
python scripts/download_demo_datasets.py
```

Takes no arguments. Writes:

| File | Source | Target column |
|---|---|---|
| `iris.csv` | `sklearn.datasets.load_iris` | `species` |
| `wine.csv` | `sklearn.datasets.load_wine` | `wine_class` |
| `breast_cancer.csv` | `sklearn.datasets.load_breast_cancer` | `diagnosis` |
| `adult_income.csv` | UCI Adult (downloaded) | `income` |
| `diabetes.csv` | `sklearn.datasets.load_diabetes` | `disease_progression` |
| `housing.csv` | `sklearn.datasets.fetch_california_housing` (downloaded, then cached) | `price` |
| `wine_quality_red.csv` | UCI Wine Quality, red (downloaded) | `quality` |

Three of these files (`adult_income.csv`, `housing.csv`,
`wine_quality_red.csv`) need internet access.

### `scripts/make_messy_demo.py`

```powershell
python scripts/make_messy_demo.py
```

Takes no arguments. Downloads Palmer Penguins (seaborn-data) and writes:

| File | Description | Target column |
|---|---|---|
| `penguins.csv` | Clean baseline (rows with missing values dropped) | `species` |
| `messy_demo.csv` | Same data, deliberately dirtied: 10–20% missing values, an all-unique `record_id` column and a high-cardinality `observer_name` column (fixed seed 42) | `species` |

### Note on the KFP pipeline

The generic KFP pipeline doesn't read this folder. It downloads its CSV from
the `--csv-url` you pass, for example the seaborn-data Iris CSV, whose column
names differ from `iris.csv` here.

## Generated files (ignored)

| Pattern | Produced by |
|---|---|
| `<name>_clean.csv` | `python generic_prep.py data/<name>.csv <target>` |
| `<name>_clean_model.pkl`, `<name>_clean_meta.json` | `python generic_train.py data/<name>_clean.csv <target>` |
| `uploads/` | CSVs uploaded through `frontend/generic_app.py`, plus their generated files |
